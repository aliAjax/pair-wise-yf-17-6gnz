# hxyfront-62005 音栓组校音台

源提示词编号：7

给管风琴维护人员使用的音栓组校音台。预置两场馆、三音栓、九支音管，每支记录音高、音分偏差、簧片状态与检修备注。

## 业务规则

- 按音栓计算全组平均偏差；单管偏离均值超过 ±3 音分（不含恰好 ±3）即判离群，整组回到「待校」。
- 重测任一音管后按最新均值重算该组；原本通过的音管若因此被动离群，只退回「待校」，历史结论全程保留（历史时间线只读追加）。
- 偏差表、音栓进度与单次维护报告共用同一份浏览器 localStorage 存档；单次维护报告归档时快照该场馆各音栓的最新判定。

## 模块划分

- `src/domain/`：判定业务模块，纯函数校音规则（均值、离群、整组状态、重测重算）。
- `src/data/`：数据业务模块，预置数据、localStorage 存档与唯一的状态仓库。
- `src/ui/`：界面业务模块，音栓进度、偏差表、维护报告三个视图。
