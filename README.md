# 音栓组校音台（hxyfront-62005）

管风琴维护人员使用的音栓组校音台：预置 **2 个场馆、3 个音栓、9 支音管**，
记录每支音管的音高、音分偏差、簧片状态与检修备注，按音栓组做均值/离群判定。

## 校音规则

- 按**音栓**计算全组平均偏差（算术平均）。
- 单管偏差偏离均值超过 **±3 音分**即判**离群**，整组回到**待校**。
- 重测任一音管后按**最新均值重算该组**：
  - 重测管本次实测，按新均值如实判定（离群 / 通过）；
  - 其他**原本已通过**的音管若因此离群，只退回**待校**（不打离群标记），
    **历史结论保留**；恢复后可重新通过，判定历史按次追加不覆盖。
- 每次重测生成一份**单次维护报告**（前后均值、离群数、连带退回明细、各管状态变化）。
- 偏差表、音栓进度、维护报告共用同一份浏览器存档：
  `localStorage["organ-tuning-console:v1"]`，支持一键恢复预置。

## 业务模块

| 模块 | 位置 | 职责 |
| --- | --- | --- |
| 判定 | `src/domain/`（`types.ts`、`tuning.ts`） | 领域类型、均值/离群/重算规则，纯函数 |
| 数据 | `src/data/`（`seed.ts`、`storage.ts`、`ids.ts`） | 预置数据、浏览器存档读写 |
| 界面 | `src/ui/` + `src/App.tsx` | 偏差表、音栓进度、重测弹窗、维护报告 |
